# Tutoriais pre-implementacao

Esta wiki organiza os tutoriais das tecnologias usadas no projeto Iziline. Os tutoriais devem ser estudados antes da implementacao, para alinhar ambiente, exemplos basicos e responsabilidades entre frontend e backend.

## Regras gerais

- Nao usar links de issues ou pull requests.
- Usar documentacao oficial ou material tecnico diretamente relacionado.
- Cada integrante deve publicar pelo menos um video curto demonstrando o exemplo do seu tutorial.
- Os exemplos devem ser pequenos, funcionais e ligados ao dominio de viagens/caronas.

## Criterio de pronto

- Quatro paginas de tutorial publicadas na wiki.
- Um video por integrante linkado no indice.
- Exemplos executaveis ou facilmente reproduziveis.
- Links externos restritos a documentacao oficial ou referencias tecnicas confiaveis.
